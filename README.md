# microbe
A fork of [micro](https://github.com/las-r/micro) that is interpreted with a stack-based bytecode VM.

The subset of micro interpreted by this is the exact same as the original, with the one exception being that it lacks file import capabilities.

## Getting Started
### Installation
```sh
pip install git+https://github.com/las-r/microbe
```

### Usage
```sh
microbe yourfile.mic
```
